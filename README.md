# Satellite Formation Flying Analysis

MATLAB project for analyzing the relative motion of the TerraSAR-X and TanDEM-X satellite formation using orbital ephemeris data.

## Overview

This project was developed as part of an Orbital Mechanics course. The objective is to analyze the relative motion between two formation-flying satellites by processing their ephemeris data and visualizing various orbital characteristics.

## Features

- 3D visualization of satellite trajectories
- Relative position analysis
- Relative velocity analysis
- Inter-satellite distance computation
- Radial velocity comparison
- Formation flight analysis

## Requirements

- MATLAB (tested on R2024a)

## Usage

Run

```matlab
main
```

to execute all analysis tasks and generate the figures.

## Data

The project uses orbital ephemeris data for the TerraSAR-X and TanDEM-X satellites.
